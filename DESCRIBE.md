# Time Check — Modrinth draft

**Title:** Time Check
**Description:** Replies with the in-game day time (ticks + human-readable).
**Command:** `/timecheck`

## Body

Replies with the in-game day time (ticks + human-readable).

### Usage

`/timecheck` — run in game chat (OP level 0 / everyone can use it).

### Installation

1. Install Forge 47.4.20 for Minecraft 1.20.1
2. Drop the jar into your `mods` folder
3. Type `/timecheck` in chat
